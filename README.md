# Milwaukee flyer demo assets

Product images (transparent PNG, named by SKU), partner logo and demo promo data for the MT26-9871 page 1 layout.
Images were extracted from the MT26-9871 flyer PDF. Demo use only; swap in Milwaukee's hosted images for production.

- `products/<SKU>.png` – 14 product cutouts
- `logos/jonestown-ag-supply.png` – partner logo
- `products.csv` – import into Google Sheets, then File → Share → Publish to web → CSV
- `products.json` – same data, bundled into the app for the first build
